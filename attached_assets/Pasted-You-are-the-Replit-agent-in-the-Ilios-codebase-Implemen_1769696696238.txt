Implement an inline “Create New…” option inside dropdown pickers used for Add User / Add Project flows so users can select existing entities OR create new ones without leaving the current workflow (Home, Onboarding, Company Admin, Project Members, Portfolio Admin). 4) Keep permissions intact:
