We reviewed the production readiness audit at ILIOS_PRODUCTION_READINESS_AND_ROADMAP.md. Proceed with the recommended Phase 0 — Production Hardening Guardrails sprint.

This sprint must be narrow, additive, and production-safety focused.

Do not implement QuickBooks. The audit confirmed QuickBooks does not currently exist beyond generic finance integration plumbing, so QBO is out of scope.

Do not implement telemetry credential migration yet. The audit confirmed production currently falls back to in-memory telemetry V2 credentials. For this sprint, warn loudly but do not fail startup. We will make durable credentials mandatory in a later telemetry sprint.

Do not refactor auth, RBAC, routing, finance, telemetry, or dashboard behavior except where explicitly listed below.

Objective

Move Ilios from “published to production URL” to “safe to leave running while we prepare for first internal users.”

The app currently has no real users and no real production data. This sprint should reduce the risk of accidental demo-data contamination, unsafe production configuration, poor browser security defaults, and poor operational visibility.

3. Tighten CORS

Replace wildcard CORS in backend/ilios-server/app/main.py.

Current risk from audit:

allow_origins=["*"]
allow_credentials=True

Implement an environment-driven allowlist.

Production allowed origins should include:

https://app.iliospower.com
the current Replit app domain if needed

Development should allow:

local frontend origin
Replit dev domain if available from env

Recommended behavior:

Use an env var such as CORS_ALLOWED_ORIGINS, comma-separated.
If unset in production, default to https://app.iliospower.com.
If unset in development, default to reasonable dev origins.
Keep allow_credentials=True.
Restrict methods to GET, POST, PUT, PATCH, DELETE, OPTIONS.
Keep headers broad for now if needed.

Acceptance criteria:

Production no longer uses wildcard CORS.
Malicious/unknown origins do not receive permissive CORS headers.
The production frontend still works.
The development frontend still works.
