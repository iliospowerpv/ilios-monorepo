You are implementing a navigation/click-path refactor for Ilios based on an approved UX contract. This is GREENFIELD (no production users, no migration/backward-compat requirements). Your goal is to make click paths consistent and short by enforcing a strict navigation contract.

HARD UX CONTRACT (NON-NEGOTIABLE)
1) Project Hub is the ONLY project-level work surface. No other module may have its own project detail pages.
   - Disallow module-specific project detail routes like:
     /operations-and-maintenance/companies/:companyId/sites/:siteId
     /due-diligence/companies/:companyId/sites/:siteId
     /finance/companies/:companyId/sites/:siteId
   These must be removed or replaced with navigation into Project Hub.

2) Project Hub owns exactly 6 tabs for a single project:
   - Overview
   - Data Room
   - Operations & Maintenance
   - Finance
   - Tasks
   - Reporting

3) Modules (O&M, Finance, Data Room) may have CROSS-PROJECT queue/list pages only.
   - These pages can include filters (company, status, etc.) but they are NOT project detail views.
   - Clicking an item in a queue must deep-link into Project Hub on the correct tab.

4) Module Entry Rule (deterministic landing):
   When a user clicks a module from left nav, they MUST either:
   A) See a Project Picker (if not scoped to a project), OR
   B) Land in Project Hub on the module’s tab (if a project is already selected in session/UI state).
   Users must NEVER be routed to a Company Overview as an intermediate step.

5) Company pages are container-only (summary/config/project lists). Company pages must not be required for Ops/Finance/Data Room work.

6) 3-click rule: Common workflows must be reachable in <= 3 clicks from module entry (or Home):
   - Upload diligence doc
   - Accept extracted field
   - Check telemetry
   - View finance snapshot
   - Resolve alert
   - Open assigned task

IMPLEMENTATION GOAL
Fix routing and click paths without a major UI redesign:
- Keep existing underlying functionality/screens where possible
- Change landing behavior, routing, and selection patterns
- Consolidate single-project work inside Project Hub tabs
