BUILD REQUIREMENTS
PART A — Data Model Enhancements (Backend)

Extend das_connections to support hub-scoped ownership:

ALTER TABLE das_connections
ADD COLUMN owner_type VARCHAR(20) NOT NULL DEFAULT 'company'
  CHECK (owner_type IN ('company', 'portfolio')),
ADD COLUMN owner_company_id INTEGER NULL REFERENCES companies(id);

CREATE INDEX idx_das_connections_owner
ON das_connections(owner_type, owner_company_id);


Semantics:

company → visible only to that company

portfolio → visible to all companies sharing the same portfolio_hub_id

owner_company_id identifies the managing (hub) company

Backfill existing records:

owner_type = 'company'

owner_company_id = company_id

PART B — Connection Discovery (Backend API)

Create new endpoint:

GET /api/telemetry/connections/available?company_id={id}


Behavior:

Resolve the company’s portfolio_hub_id

Return:

company_connections → owned by this company

portfolio_connections → owned by companies within the same hub where owner_type = 'portfolio'

Response shape:

{
  "company_connections": [...],
  "portfolio_connections": [...]
}


Authorization:

User must have access to the company

Portfolio connections only returned if hub matches
