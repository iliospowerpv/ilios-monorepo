Approve the Phase 2 plan with the following confirmed decisions and refinements.

Decision #1 approved:

Reuse `module_wattage` as the single canonical field for module nameplate power at STC.

* Canonical key: `module_wattage`
* Canonical semantic: per-module STC/nameplate power
* Canonical unit: W per module
* UI label for this Module Datasheet context: “Module Nameplate Power at STC”
* Do not create a competing `module_power_stc_w` canonical field or candidate fact.
* A parser-level display alias may exist only inside parsed metadata if useful, but it must map to `module_wattage` before DocumentKey/candidate-fact creation.

Reason:
There must be one canonical, baseline-driving truth path for module per-unit nameplate power. Separate `module_wattage` and `module_power_stc_w` facts would create avoidable divergence and reconciliation conflicts.
